
# आरती संग्रह (Aarti Sangraha)

> **Special Customised Edition for Ganesh Festival**

This is a fully customised, mobile-centric web app for reading and navigating a collection of aartis (आरती) in the exact sequence and selection that we pray during Ganesh festival in our tradition. The order, content, and aartis are tailored specifically for our family and community's Ganesh Utsav.

## Features
- 📜 Collection of 15+ aartis in the exact order we use for Ganesh festival, including Ganpati, Shankar, Devi, Datt, Vithoba, Ram, Narmada, and more
- 🧭 Sticky, scrollable navigation bar for quick jumps to any aarti
- 📱 Fully mobile responsive
- 🔖 Automatic highlighting of the current aarti in the navigation bar
- 🕉️ Special section for अष्टविनायक (Eight Ganpati Temples)

## Usage
1. Open `index.html` in any modern web browser (mobile or desktop).
2. Use the top navigation bar to jump to any aarti instantly.
3. The navigation bar will highlight the aarti you are currently reading.

## Structure
- `index.html` — Main HTML file with all aarti content and navigation
- `style.css` — All styles, including glassmorphism and responsive design

## Customization
- This version is already fully customized for our Ganesh festival sequence. To change the order or content, simply update `index.html`.
- To change the look, edit `style.css`.
